# SIMPEG-ASSET

Sistem Informasi Manajemen Kepegawaian, Asset, dan Form Ulasan Pegawai Pemerintah dengan Perjanjian Kerja.

## Status

This workspace now contains a Laravel MVC skeleton for:

- authentication stubs
- dashboard shell with chart placeholders
- employee module scaffolding
- asset module scaffolding
- PPPK review module scaffolding
- reporting and settings pages
- migrations, models, requests, seeders, and basic controllers

## Next setup steps

1. Install project dependencies with Composer.
2. Run Laravel Breeze installation and publish assets.
3. Configure MySQL credentials in `.env`.
4. Run migrations and seeders.
5. Build the remaining CRUD forms, exports, QR code flow, and role-specific workflows.
